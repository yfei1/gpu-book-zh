part[2i]（pA，CTA A 前半行部分和）part[2i+1]（pB，CTA B 后半行部分和）y[row]（正确合并结果）命中旧行 / 算错的 y[row]（仅 relaxed 反例）release 等待（推断在等前序写到 L2；带 1 笔在途写时原子加实测多约 30 周期）L1B 旧缓存行（假设本 kernel 早先读过同线，示意）L1 行已作废（实测观察：整块私有 L1 作废）在途未到 / 按内存模型推断的位置

用顶部的卡片和步进控件，对照上方算法条带、中间缓存图与底部顺序时间线。各流多处理器的私有缓存之间不自动保持一致，交接时需在计数器上配对全卡范围的释放与获取，才能按规范保证部分和可见。

细节
  • 跨 SM 合并与免同驻：两个半行 CTA（全卡 132 个 SM 中的 2 个，位置示意）经 60 MiB 共享 L2 与 thread_scope_device（全卡范围）的 acq_rel 原子加合并部分和；各 SM 私有 L1 之间不自动保持一致，且先到者（旧值 0）做完原子加即退出，不要求两块同时驻留。
  • 规范可见性保证：规范上，cnt[i] 上的 release 与 acquire 成对同步保证 part[2i] 可见。
  • 私有缓存作废观察（落在本卡硬件上，非规范保证）：重读测试在一条全卡 acq_rel 栅栏（fence.acq_rel.gpu）后实测观察到整块私有 L1 被作废，1 个 CTA 重读 16 KiB 的 xxx 由 L1 有效时的 319.8 变慢到 596.6 个周期；原子加之后的重读代价没有测。
  • 回读与交接耗时：从 L2 读回约 328 个周期（按约 1.8 GHz 折算约 0.18 µs，远近分区差没有测）；v3 无等待合并没有测，带轮询的交接微基准约 0.67 µs。
  • 在途写等待与目标推断：带 1 笔在途写时，单线程 acq_rel 原子加实测多等 27.5–31.1（约 30）个周期（1,047.2–1,050.8 → 1,078.3 周期，折算约 0.60 µs；单独测那条全卡 acq_rel 栅栏则多等 +206 个周期，即 269 → 475 周期），其等待前序写入到达 L2 的目标按内存模型推断（没有用硬件计数器核实）。
  • 无顺序约束反例与两种独立隐患：relaxed 反例（单线程约 506 周期，比 acq_rel 少 572 周期）画的是规范允许的一种执行（本卡没有测），展示计数先到 L2 或命中未作废 L1B 旧行这两种独立隐患。
