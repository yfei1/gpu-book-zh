颜色 = 独立数据对象（实色 = 已发或在途；仅顶部队列条用实色淡化表已完成）：模式 1–2 按 uint4（蓝/青 = 前方链 a[p]/a[q]，紫/琥珀 = 备后方 u⁺⁰/u⁺¹，示意）；模式 3 按元素编号（0 蓝、1 青、2 紫、3 琥珀、4 洋红，循环前元素 −3 深绿、−2 棕褐、−1 橄榄绿）白底粗黑框 = 本周期在用的调度器或管线通道（时间线光标右侧浅空心框 = 尚未到达的未来槽位）冷灰部件 = 调度器等目标管线空出红斜纹 = 目标算术管线忙引起的发射槽空等周期（管线节流停顿）冷灰实框「待发」= 排在队首等目标管线空出的指令虚线框「未测」= 模式 2 假定两条 FFMA 各走 16 通道半管线与 IMAD 重叠（没有测）

固定同一个单 warp（n = 1，1 个周期 = 1 个 SM 时钟周期），模式 1–2 在展开批内让每个 uint4 维护单条持久累加链（示意交错两条独立链 a[p]、a[q]，每个 uint4 的 4 对字跨两个相邻切片拆完）并为后方 uint4 提前拆包；模式 3 让同一轮同时处理不同元素（跨元素流水，又称软件流水），看多周期管线（ALU 2 周期、SFU 8 周期）何时让顺序调度器的发射槽空等；跨管线延迟没有测，按同管线链实测值建模。
