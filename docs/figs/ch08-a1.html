细节
  • 整体范围与供数边界：共 16 步，展示每页 1 个词元下的三跳指针等待与隐藏；数据存放在 6 栈共享 HBM 中（哪一栈存哪些字节未指定），第 1、2 跳由 L2 还是 HBM 供数没有测。
  • 「三跳串行入口」配置与比例（检验 1 请求全长）：单头 wgmma 检验 kernel，256 线程、4 槽 32 KiB 环形缓冲；时间轴按 0..2,390 ns 单一线性比例绘制，灰斜纹为跳内算页号/地址示意子段。
  • 「三跳串行入口」各跳实测：读第 0 块 8 KiB KV 之前依次走完读 seq_lens[b]（约 600 ns）→ 读 64 项 page_table（256 B，到达间隔 640 ns，首次用槽号算源地址的整数乘加占 PC 停顿采样的 37%–42%，采样定义见第 10 章第 7 节）→ 单头 KV cp.async 落入槽 0（到达间隔 1,150 ns，此时生产者已转去推进块 1，精确卡点没有测），合计 2,390 ns（约 2.4 µs）。
  • 「批大小 B = 1：头两跳并发」配置与并发预读（解码 1 请求全长）：切换为两头解码切段 kernel，双头 16 KiB/块、3 槽 48 KiB 环形缓冲，时间轴按 0..7,040 ns 单一线性比例画各 CTA 中位数时间戳；按启动参数 max_pages 将 seq_lens[0]（4 B）与前 4 块页表（1 KiB：仅块 0 的 256 B 受首个 cp.async 约束在 ≤ 1,088 ns 就绪，块 1..3 的 768 B 落地时刻没有测）并发发出。
  • 「批大小 B = 1：头两跳并发」各 CTA 中位数前移：区间核对（代价 0.000 µs，其后含等前一个序言 kernel 的 PDL 等待调用，耗时没有测）、首组 KV 发出（块 1 单块落地时刻没有测，时间轴在 1,089.2 ns 画块 1 的开口虚线桩）、首块落地与约 5 块主循环结束的四处各 CTA 中位数从 1,024 / 1,248 / 3,552 / 7,040 ns 前移到 832 / 1,088 / 3,520 / 6,912 ns（−128 ns）。
  • 「批大小 B = 1：头两跳并发」整算子配对与检验对照：下方独立读数框给出整算子 S 系列配对（256 个切段 CTA 加按对数分母汇总部分结果的合并 kernel）实测省 0.26 µs（Δ = −0.256 µs，95% 置信区间 [−0.272, −0.240] µs，另一场独立配对省 0.192 µs，余下 128 ns 来源没有测）；检验 1 请求全长 K 循环完 +40 ns 无收益未采用。
  • 「循环内页表提前读：三次演进」范围与改前状态：两头解码全长 kernel，每块始终读 256 B int32 页表、3 槽环内同时两块 KV 在途，横轴仅示意先后顺序与轮次代码距离；改前（提前 1 轮）算块 j 仅隔 1 块计算重叠 j+3 读取，随后拼 int64 slots_pf 的整数乘加卡在 j+3 记分牌上（指令位置与循环内往返耗时均没有测）。
